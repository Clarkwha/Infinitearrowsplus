# Infinite Arrows Plus

**A Valheim mod that prevents arrow consumption.**  
Created by Chikn

## Features

- **Unlimited Arrows:** Prevents arrows from being consumed when firing bows.
- Lightweight and non-intrusive.
- Compatible with most other mods.

## Installation

### Using Thunderstore Mod Manager (Recommended)

1. Open [Thunderstore Mod Manager](https://www.overwolf.com/app/thunderstore-thunderstore_mod_manager).
2. Search for **Infinite Arrows Plus**.
3. Click "Install with Mod Manager."
4. Launch the game from within the mod manager.

### Manual Installation

1. Download and install **BepInEx** for Valheim.
2. Download the mod DLL file.
3. Place `InfiniteArrowsPlus.dll` into your `BepInEx\plugins` folder.
   - Usually found at:  
     `C:\Users\<YourUsername>\AppData\Roaming\Thunderstore Mod Manager\DataFolder\Valheim\profiles\Default\BepInEx\plugins`
4. Launch Valheim as usual.
